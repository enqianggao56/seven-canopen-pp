# 2026-11-24 实机小位移 PP 测试，排除 Node 5

Node 1、2、3、4、6、8 在真实 `can0` 上完成 T = 3 s 的六轴同步去程和回程。随后三动三保持试验的去程完成，回程因装载当周期缺少 Node 4 速度反馈而中止。首轮试验结束时的状态反馈确认六个参与节点均为 Switch On Disabled。Node 1、4、6 当时停在混合去程一侧。随后复测完成了从新起点出发的混合往返，详见文末。

## 控制范围与试验条件

- 使用 1 Mbit/s、100 ms SYNC 和仓库的初始化、使能及 PP 握手。目标临时按稳定实测位置生成。现场已确认急停、防坠支撑及轴 5 固定或隔离条件。测试程序在 CAN 发送入口限制目标节点，在批次入口限制允许触发的轴和位移。
- 全部四段独立 `candump` 抓包合计 6603 帧。发往 Node 5 的 NMT、SDO 请求、RPDO 和广播 NMT 均为 0 帧。总线上的 SYNC 为广播。第一段捕获的 185h、285h 各一帧，载荷长度均为零，所以无法从抓包测量轴 5 的机械位移。
- 首轮读得 Node 7 为 1040 inc，按当前多圈标定对应 −361.0546875°，配置下限为 −360°。首轮在使能前中止，后续控制名单排除 Node 7。其后收到的 Node 7 位置反馈均为 1040 inc。
- 六轴首次使能后，Node 2 首帧与稳定位置相差 0.15747 mm，超过 0.02 mm 到位窗口。试验守卫在“全部保持”阶段拦下了意外参数装载，控制器确认整组失能。后续使用连续稳定反馈生成试验目标，全部保持用例未发运动上升沿。
